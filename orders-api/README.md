# Orders API — Serverless REST API with AWS Lambda & API Gateway

This subdirectory contains the Java 17 Maven project for the Orders Serverless API.

Please see the comprehensive report, architectural diagrams, checkpoint answers, and evaluation in the main repository [README.md](../README.md).

## Quick Commands
* **Run Tests**: `mvn test`
* **Package Uber-JAR**: `mvn package`
* **SAM Deploy**: `sam deploy --guided`
